## 2026-09-29: Stack versions (verified at install)

Next.js 16.3.6, React 19.2.8, TypeScript 5.9, Tailwind CSS 4.3, pnpm 12.8, Node 24 (`.nvmrc`).
`cacheComponents` stays off. Consequence: route segment config (`revalidate`, `dynamic`,
`dynamicParams`) drives rendering, as the spec intends.

## 2026-09-29: `revalidateTag` signature

Verified in `node_modules/next/dist/docs/01-app/03-api-reference/04-functions/revalidateTag.md`:
`revalidateTag(tag, profile)`; the one-argument form is deprecated. `/api/revalidate` calls
`revalidateTag(tag, { expire: 0 })` so the next visit regenerates instead of serving stale.

## 2026-09-29: Upstream latency shapes the queries

Measured: `count(*)` over precipitation ~45 s; rows per year ~23 s; rows per department over
the whole table ~100 s; one department over 30 days ~3 s. Therefore:

- The catalog derives the row count from the per-year query (same URL as the dataset page,
  so the Data Cache fetches it once).
- Department figures on dataset pages use a 30-day window.
- The SSR dashboard queries one region over 14 days.
- ISR pages set `maxDuration = 300`.

## 2026-09-29: Hero chart uses climatological normals

The home hyetograph shows IDEAM 1991-2020 monthly rainfall normals for the El Dorado station
(Bogotá), dataset `nsz2-kzcq`, generated by `pnpm data:hero`. Summing raw telemetry for a
whole department is not a meaningful rainfall figure; a station normal is.

## 2026-09-29: Cross-origin isolation scoped to /explore and /lab

COOP `same-origin` + COEP `require-corp` only on those routes (`next.config.ts`). All links
into them are plain `<a>` (full navigation). Everything on them is same-origin: DuckDB assets
are copied to `public/duckdb/<version>/` at dev/build, fonts are self-hosted by `next/font`.

## 2026-09-29: DuckDB-Wasm version

npm `latest` for `@duckdb/duckdb-wasm` is `1.33.1-dev57.0` (the package only publishes dev
tags). The copy script is wired into `dev`/`build` directly because pnpm does not run
`pre*` scripts by default. Each wasm bundle is ~35-41 MB uncompressed.

## 2026-09-29: Dependencies

- `@tanstack/react-virtual`: virtualized result table. `@tanstack/react-table` was not needed.
- `apache-arrow` removed: DuckDB-Wasm ships its own copy and types conflicted.
- `tsx`: run TypeScript ETL scripts. `@duckdb/node-api`: CSV to Parquet in the ETL.
- `jsdom`, `@vitejs/plugin-react`: component unit tests.

## 2026-09-29: Theme without cookies

Theme lives in `localStorage` and a blocking inline script sets `data-theme` before paint.
No cookie is read on the server, so SSG/ISR stay static.

## 2026-09-29: Hyetograph bar edge

Pale YlGnBu classes fail 3:1 against `fog`. Every bar gets a 1px inset edge at 40% `basalt`,
so bars meet WCAG 1.4.11 without changing the specified ramp.

## 2026-09-29: ISR pages and the build timeout

Vercel builds failed with "took more than 60 seconds" on `/datasets` and `/datasets/[id]`.
`staticPageGenerationTimeout` is now 300 s, and `/datasets/[id]` returns no static params, so
each dataset page renders on its first visit and is then cached and revalidated hourly.
